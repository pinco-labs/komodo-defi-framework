coin pair, event names and direct event.data.tx_hash fields only.

No wallet secrets, full transaction bytes, addresses or configuration are copied.

on-chain verification. They do not by themselves prove the runtime binary,
HTTPS-only transport, absence of legacy RPC, or a swap using API2.
Spent events without a direct tx_hash are preserved without inventing a hash.
Extraction performs no RPC, network request, transaction or runtime change.
